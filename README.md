## 📥 Instrucciones de Instalación

### Extensiones de Navegador (Chromium / Chrome / Brave / Edge)
1. Descarga el archivo `.zip` de la extensión correspondiente desde la tabla superior.
2. Descomprímelo en una carpeta local de tu preferencia.
3. Abre en tu navegador `chrome://extensions` (o `brave://extensions` / `edge://extensions`).
4. Activa el **Modo de desarrollador** (*Developer mode*) en la esquina superior derecha.
5. Haz clic en **Cargar descomprimida** (*Load unpacked*) y selecciona la carpeta descomprimida.
